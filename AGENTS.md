# AGENTS.md

## Caption voting
- Upvoting or downvoting a caption inserts a new row into `caption_votes`.
- Use `vote_value` of `1` for upvotes and `-1` for downvotes.
- A database trigger updates `captions.like_count`; this repo should not write to that column.
- Before inserting a new vote, remove any existing `caption_votes` rows for that user+caption.
- If the user clicks the same vote again, delete their `caption_votes` rows for that caption (no vote).

## Data conventions
- The database uses cascade deletes; do not manually delete related rows when deleting a record.

## Supabase schema
- The latest database types live in src/types/supabase.ts
- This is generated by running npm run supabase:types
- The user does not want to use a SUPABASE_ROLE_KEY.  All actions should use the logged-in user's JWT key.

## Workflow
- Before finishing work, run `npm run build` to ensure there are no build errors.

## Animation
- Always show the app's animations, regardless of `prefers-reduced-motion`.
- Do not add `motion-reduce`, `motion-safe`, or reduced-motion checks that disable or reduce animation.
- Keep Framer Motion's `reducedMotion` policy set to `never` (its default).
